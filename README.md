# 《窗台多肉铺的猫店长》

轻治愈暖色调网页解谜养成游戏。玩家辞掉 996 后回到老社区，接手外婆空置三年的多肉铺，与左耳缺角的三花猫店长一起整理铺面、接待客人、修复后院花房，并拼回外婆、阿花和自己的二十八年记忆。

## 文件说明

- `index.html`：入口页面。
- `style.css`：参考手账蜡笔简笔画风格设计的暖色界面、植物/猫/场景/粒子动效样式。
- `game.js`：12 章主线、32 植物图鉴、50 成就、41 彩蛋、猫养成、本地存档逻辑，以及点击小猫的喵叫反馈。
- `paywall.js` / `paywall.css`：沿用旧作风格调整后的 1 元支持弹窗。
- `paycode.png`：收款码图片。
- `cover.png`：16:9 手账蜡笔风封面图。
- `start_cover.png`：游戏开始界面主视觉图。
- `cat_sprite.png`、`plant_sprite_01.png` 至 `plant_sprite_12.png`：从开始界面同图裁切出的猫与植物贴纸素材，供游戏内直接使用。

## 运行方式

直接双击 `index.html`，或部署到 GitHub Pages。进度保存在当前浏览器本地缓存中。

每日 17:00–20:00 会触发限定流星雨、萤火虫罐和夜光草彩蛋；结尾自由营业页也提供预览按钮，方便检查效果。
